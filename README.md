Emberward is a tower defence game that plays offline in a desktop browser from its own static files. The Emberheart is the last living flame, and twelve waves of ash-wraiths are marching the winding road to snuff it out — build Spark Spires, Frost Bells, Ember Mortars and Storm Prisms on the lantern plots, spend ember shards, upgrade spires to level 3, and hold all twelve waves to break the Ash King, the wave-12 boss who costs five hearts if he reaches the flame. Wisps come in crowds, Moths split in two when they fall, Brutes shrug off weak shots, and the flame has only 20 hearts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a lantern plot to build the selected spire (1–4 pick the kind), U upgrades, X sells, SPACE starts the next wave, F doubles the speed, P pauses, R restarts.
